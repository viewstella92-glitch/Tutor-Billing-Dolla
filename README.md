# Tutor Desk — สมุดบริหารงานติวเตอร์

เว็บแอปจัดการงานติวเตอร์ส่วนตัว: รายชื่อนักเรียน ตารางสอน บันทึกคาบจริง ค่าสอน/การชำระเงิน และรายงานรายเดือน

## ฟีเจอร์
- Dashboard แสดงยอดค่าสอนเดือนที่เลือก เงินที่รับแล้ว ยอดค้างรับ และยอดที่ยังไม่ได้แจ้ง
- จัดการรายชื่อนักเรียนและอัตราค่าสอน
- ตารางสอนประจำสัปดาห์และคาบเฉพาะวัน
- บันทึกคาบสอนจริง พร้อมชั่วโมง อัตราค่าสอน และหมายเหตุ
- ติดตามการแจ้งค่าสอนและการชำระเงิน
- สรุปรายเดือนและส่งออกประวัติคาบสอนเป็น CSV
- ใช้ Supabase เพื่อให้ข้อมูลซิงก์ข้ามอุปกรณ์

## เริ่มใช้งาน
ต้องตั้ง Environment Variables ใน Vercel:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

รันในเครื่อง:
```bash
npm install
npm run dev
```

## ข้อมูลเริ่มต้นใหม่
แอปเวอร์ชันนี้ใช้ namespace ผู้ใช้ภายในชุดใหม่ จึงไม่อ่านหรือย้ายข้อมูลจาก Local Storage หรือ namespace เดิม ข้อมูลเก่าในฐานข้อมูลไม่ได้ถูกลบ แต่จะไม่ถูกแสดงในแอปชุดใหม่นี้

## ตาราง Supabase ที่ใช้
โค้ดอาศัยตารางเดิมที่มีอยู่:
- `tutor_students`: `id, user_id, name, rate, grade, subjects, notes, status, created_at`
- `tutor_schedule`: `id, user_id, student_id, recurring, day, date, start_time, end_time`
- `tutor_sessions`: `id, user_id, student_id, student_name, session_date, hours, rate, note, invoiced, paid, source_slot_id`

ควรเปิดใช้ Row Level Security (RLS) และกำหนดนโยบายการเข้าถึงข้อมูลอย่างเหมาะสมก่อนใช้งานกับข้อมูลจริง โดยเฉพาะเมื่อไม่มีระบบล็อกอิน

## หมายเหตุ
- รายได้และยอดค้างรับคำนวณจากคาบสอนที่บันทึกจริง ไม่ใช่การคาดการณ์จากตาราง
- การส่งออก CSV เป็นการสำรองข้อมูลสำหรับนำไปเปิดในสเปรดชีต ไม่ใช่ระบบสำรอง/กู้คืนอัตโนมัติ
